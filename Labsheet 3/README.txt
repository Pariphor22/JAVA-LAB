JAVA LABSHEET 3 - ARRAYS

Contains 30 separate Java programs (Question01.java to Question30.java).
Part A: 1-D arrays (Q1-Q6)
Part B: 2-D arrays (Q7-Q13)
Part C: 3-D arrays (Q14-Q18)
Part D: Jagged arrays (Q19-Q20)
Part E: Additional questions (Q21-Q30)

Run a program from Terminal:
javac Question01.java
java Question01

Replace 01 with the question number you want to run. JDK 21 or higher recommended.
