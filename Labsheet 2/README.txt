JAVA LABSHEET 2 — 30 PROGRAMS

Files:
- Question01.java through Question30.java
- Each question is saved in a separate Java file.
- JDK 21 or higher is recommended.

How to run a program:
1. Open Terminal in this folder.
2. Compile: javac Question01.java
3. Run: java Question01

Replace 01 with the required question number.
Most programs ask for input when they run.

Notes:
- Question 20 uses the sample password: java123
- Question 24 uses an array of 5 integers.
- Question 25 uses 3 students and 3 subjects.
- Question 17 rotates a 32-bit integer left by 2 positions.
- Question 30 treats the third bit as bit position 2 (counting from 0).
